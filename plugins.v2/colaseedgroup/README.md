# 可乐保种组（MoviePilot 插件）

把可乐PT 的**官方种**按档位搬进下载器长期保种。从「可乐PT辅种」拆出来的独立插件 —— 只做保种，不含辅种，两者可以同时安装、各配各的下载器。

## 它做什么

1. **按档位保种**：`2T / 5T / 10T / 15T / 20T / 自定义（100M·100G·1T·1P）/ 全站官种`
2. **体积只超不少**：官方优先、同优先挑大的；能一颗盖住剩余空间就挑其中最小的（超额最少）
3. **进种限流**：客户端里「正在下载」达到上限（默认 5，可调）就停止进种，等这批下完再补 —— 让覆盖稳步追平，而不是一次塞几百颗互相抢带宽
4. **达标后动态轮换**：删做种人数最多的 N 颗、补最少的 N 颗（强制开启）
5. **下架自动清理**：每轮回站点核对 `status`，下架的种子删掉（可选连文件一起删）
6. **多客户端单独限速**：只对保种生效，辅种不碰
7. **每轮上报**：档位 / 覆盖 / 缺口 / 限速 / 做种时长 → 站点据此算月度考核与退休进度

## 解锁条件

只有**站点工作组**账号能用。登录后插件会读本人资料里的工作组头衔，没有的账号保存配置时会被强制关掉并写明原因。

## 配置

| 区块 | 内容 |
|---|---|
| ① 账号 | 可乐PT 用户名 / 密码 / 验证码（首次登录用） |
| ② 下载器 | 用 MP 已配置的，或按行填 `地址,用户名,密码`（Transmission 写 `tr,地址,...`） |
| ③ 保种组 | 档位、运行周期（默认每小时）、进种限流、保存路径、跳过校验、下架清理方式、动态轮换 |
| ④ 保种限速 | 全局 + 每客户端单独覆盖 |

## 几个坑（踩过）

- **跳过校验别对新下载的种子开**：它是「文件已在磁盘、种子丢了」的恢复场景用的。保种是从站点新下载的，开着它 qB 会认为文件已完整，全部变成「丢失文件」、进度 0、永远下不动。
- **下架清理选「连文件删」前想清楚**：文件是真删，硬链接共享的副本不受影响，独立副本删了要重下。
- **运行周期别低于 1 小时**：站点对连续请求有限流，而且每轮的「下架核对」是每颗种子一次 GET。

## 与「可乐PT辅种」的关系

同一个仓库里的两个独立插件：

- `ColaCrossSeed`（可乐PT辅种）—— 跨站辅种
- `ColaSeedGroup`（可乐保种组，本插件）—— 保种组

配置与数据按类名隔离，互不影响。只想保种就只装这个。
